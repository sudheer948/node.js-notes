# Namaste Node.js — Episode 2

Short notes covering the fundamentals of **Node.js, V8, JavaScript engines, and ECMAScript**.

## Topics Covered

* JavaScript running outside the browser
* Client vs Server
* Why Node.js enables full-stack JavaScript
* V8 JavaScript Engine
* How JavaScript is executed
* Node.js internals
* Node.js = V8 + server-side APIs/modules
* ECMAScript and ES6
* TC39
* Relationship between Node.js and V8
* Basic Node.js interview questions

## Key Takeaway

> **Node.js is a C++ application that embeds the V8 JavaScript engine and provides additional server-side APIs, allowing JavaScript to run outside the browser.**
